# GitHub Pages 公開用

このフォルダの内容をGitHubリポジトリへ配置すると、iPhoneへホーム画面アプリとして追加できます。

日付OCR・画像解析・ICS生成はブラウザ内で行われます。選択した画像や勤務データをサーバーへ送信するコードはありません。OCRプログラムは公式npm CDNから取得しますが、画像認識は端末内で実行します。

## 公開後の使い方

1. GitHub PagesのURLをiPhoneのSafariで開きます。
2. 共有ボタンから「ホーム画面に追加」を選びます。
3. ホーム画面の「ナスカレ取込」を起動します。
4. スクリーンショット2枚を一度に選び、勤務表の1列目または2列目を読み取ります。左端の日付もOCRするため、選択順は問いません。
5. 結果と勤務時間を確認してICSを書き出します。

初回にページを完全に読み込んだ後は、Service Workerのキャッシュによりオフラインでも起動できます。
